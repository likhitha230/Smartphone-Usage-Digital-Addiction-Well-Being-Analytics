Smartphones have become an important part of everyday life. People use smartphones for communication, entertainment, gaming, education, work, and social media.
However, excessive smartphone usage can lead to increased screen time and smartphone dependency.
This project analyzes smartphone usage data to answer questions such as:
1. How much time do users spend on smartphones daily?
2. Which age groups have higher smartphone usage?
3. How does smartphone usage differ between genders?
4. How many users have high screen time?
5. What is the relationship between screen time and addiction level?
6. How does gaming time contribute to smartphone usage?
7. How does weekend screen time differ from regular usage?
8. How does smartphone usage relate to academic/work study hours?
📂 Dataset
The project uses a Smartphone Usage dataset containing information about users and their smartphone usage behavior.
Example Features
Feature	Description
Age	Age of the user
Gender	Gender of the user
Daily Screen Time Hours	Average daily smartphone screen time
Gaming Hours	Time spent on gaming
App Opens Per Day	Number of times applications are opened per day
Weekend Screen Time	Smartphone usage during weekends
Academic/Work Study Hours	Hours spent on academic or work-related activities
Addiction Level	Level of smartphone addiction/dependency


Feature names may vary depending on the dataset used.

🔄 Data Analysis Process
1. Data Collection
The dataset contains information related to users' smartphone usage behavior and daily activities.
The data includes demographic information and different smartphone usage metrics.
2. Data Preprocessing
The raw dataset is cleaned and prepared before analysis.
Major preprocessing steps:
- Checking missing values
- Removing duplicate records
- Checking incorrect data
- Verifying data types
- Cleaning categorical values
- Formatting numerical values
- Checking outliers
- Removing unnecessary columns
3. SQL Analysis
SQL is used to analyze the smartphone usage dataset and generate useful metrics.
Examples of analysis include:
- Average daily screen time
- User count by gender
- Screen time by age group
- Average gaming hours
- Addiction-level distribution
- Weekend screen time
- Academic/work study hours
- High screen-time users
